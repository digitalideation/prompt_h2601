# PromptVision: facilitation notes

The student instructions are in [the activity guide](../activities/promptvision.md). These materials are carried over from the previous semester; the H26 activity details are still to be adapted.

- Confirm team numbers, theme, track length and submission location before using the guide.
- Use a countdown timer for the creation sprint.
- Collect tracks into a playback order, check file playback and bring volumes to a consistent level.
- Present the entries with their prompts, then run the voting ceremony.
- Give brief feedback on selected tracks and invite peer comments on prompt clarity, sound design and emotional intent.

See [audio-session teaching notes](day02.md) for demonstrations and discussion cues.
