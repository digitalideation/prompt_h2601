# Artistic Telephone: teaching notes

The student instructions are in [the activity guide](../activities/artistic_telephone.md). Use [Session 1 teaching notes](day01.md) for the lesson sequence.

## Before class

- Prepare six SWITCHdrive group folders and test upload/download access. Provide a separate practice folder.
- Confirm the class model, supported inputs, cost and latency.
- Pilot one round, including multiple attempts, selecting an earlier attempt, and transferring the original PNG.
- Assign group letters A to F, seats 01 to 05, and one theme per group: Serenity, Ritual, Metropolis, Decay, Connection or Chaos.
- Use a visible timer and announce each round together. Reserve the final minute for selection and transfer.
- The full game produces 150 selected images. Allow for additional attempts when setting the spending budget.
- If latency is too high, reduce the number of rounds explicitly. Keep prepared generated chains available if live generation is unavailable.

## Reveal

Download all original group PNGs and use [the reveal notebook](../notebooks/03_telephone_reveal.ipynb). Confirm that all groups are represented, resolve duplicate positions and inspect missing records.

Show one chain per group, or fewer if discussion needs more time. Reveal prompts after students have compared the images. Optional highlights include Most Surprising Transformation, Best Stylistic Leap and Strongest Narrative Continuity.

Export the HTML gallery only after play. It includes the prompt text even while the reveal controls are collapsed. See [notebook preparation notes](notebooks.md) for technical checks.
